# Field Profitability Ledger

Release downloads and support for Field Profitability Ledger, a Farming Simulator 25 mod for PC/Mac single-player.

Download from [ModHub](https://www.farming-simulator.com/mod.php?mod_id=369866) or [GitHub Releases](https://github.com/user01010111/FS25_FieldProfitabilityLedger/releases/latest). Put the ZIP in your mods folder without unpacking it, then enable it for your save. Open the ledger with **Left Alt+L**.

Report bugs or suggestions through [GitHub Issues](https://github.com/user01010111/FS25_FieldProfitabilityLedger/issues). Include the mod/game versions and steps to reproduce; remove personal details from any logs.
